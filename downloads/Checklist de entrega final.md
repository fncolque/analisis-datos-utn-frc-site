# Checklist de entrega final

## Caso y derechos

- [ ] caso identificado;
- [ ] derechos o autorización;
- [ ] anonimización revisada;
- [ ] datos sensibles retirados;
- [ ] video restringido.

## Decisión

- [ ] audiencia;
- [ ] decisión;
- [ ] KPI definido;
- [ ] acción;
- [ ] límite.

## Datos y arquitectura

- [ ] fuentes;
- [ ] grano;
- [ ] modelo;
- [ ] pipeline;
- [ ] responsables;
- [ ] frecuencia;
- [ ] cuatro trade-offs.

## Calidad

- [ ] controles técnicos;
- [ ] reglas de negocio;
- [ ] linaje;
- [ ] seguridad;
- [ ] respuesta a defectos.

## Evidencia

- [ ] ejecución;
- [ ] filas;
- [ ] total;
- [ ] reconciliación;
- [ ] caso límite;
- [ ] interpretación prudente.

## Consumo

- [ ] visual adecuado;
- [ ] título con mensaje;
- [ ] fuente;
- [ ] actualización;
- [ ] recomendación;
- [ ] accesibilidad.

## IA y equipo

- [ ] IA declarada;
- [ ] verificación;
- [ ] contribuciones;
- [ ] participación de todos;
- [ ] cada integrante puede defender su parte.

## Archivos

- [ ] video 10–15 min;
- [ ] enlace probado;
- [ ] dossier dentro del límite;
- [ ] anexos;
- [ ] nombres y versiones;
- [ ] copia de respaldo.
